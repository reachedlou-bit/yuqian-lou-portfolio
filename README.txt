Yuqian Lou — Personal Job Search Website

Preview: extract this ZIP and open index.html in a browser. Keep the assets folder beside index.html.

Free publishing with GitHub Pages:
1. Create a GitHub repository (e.g. yuqian-lou-portfolio).
2. Upload all files and folders from this package.
3. Go to Settings → Pages.
4. Choose Deploy from a branch, branch main, folder /(root), then Save.
5. GitHub Pages will publish a public URL.
